# dndbuilder

An open-source, cross-platform (Linux and Windows) character builder for D&D 5th edition, compatible with
**[Aurora Builder](https://aurorabuilder.com/)** content files.

Aurora was a well-loved Windows-only builder whose development stopped around 2020. Its data format lives on in the
community-maintained [AuroraLegacy/elements](https://github.com/AuroraLegacy/elements) repository. dndbuilder is a
from-scratch reimplementation of the rules engine, with a modern UI that you can keep developing:

* loads Aurora `.xml` element files and `.index` content indexes, including updates from the AuroraLegacy repository;
* builds characters with races, classes, multiclassing, backgrounds, feats, ASIs, spells and equipment, driven entirely
  by content rules;
* computes the full sheet (abilities, saves, skills, AC, HP, speeds, proficiencies, features, spellcasting) with
  breakdowns showing where each number comes from;
* imports Aurora `.dnd5e` character files;
* includes a searchable compendium of everything loaded;
* runs as a native desktop app (Tauri) on Linux and Windows. The UI also runs in a plain browser for development.

> **About content.** The app ships with the rules plumbing (`content/core`) and the
> [System Reference Document 5.1](https://dnd.wizards.com/resources/systems-reference-document) (`content/srd`), which
> is licensed under [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/): nine races, the twelve classes with one
> subclass each, the Acolyte background, equipment and 315 spells, so it works out of the box. It does not ship any other
> copyrighted game content. Load content you own or that is openly licensed, from an index URL or your own XML files.
> SRD element ids match the community content, so characters stay valid when you add more sources.

## Repository layout

| Path | What |
|---|---|
| `packages/engine` | TypeScript rules engine: XML parser, content registry, expression language, resolver, stat calculator, sheet builder, Aurora import. No UI or platform dependencies. |
| `apps/desktop` | React UI and Tauri v2 desktop shell (`src-tauri`). |
| `content/core` | Built-in system content, generated by `scripts/generate-core.mjs`. |
| `content/srd` | Built-in SRD 5.1 content (CC-BY-4.0), generated by `scripts/generate-srd.mjs` from data in `scripts/srd/`. |
| `docs/aurora-format.md` | Behaviour reference for the content format: read this before changing the engine. |

## Getting started

Requirements: Node.js 20+; for the desktop build, Rust (stable) and the
[Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) (on Debian/Ubuntu: `libwebkit2gtk-4.1-dev`,
`librsvg2-dev`, `patchelf`; on Windows: WebView2, which ships with Windows 10/11).

```sh
npm install
npm test                 # engine unit + integration tests
npm run dev              # UI in the browser at http://localhost:1420
npm run tauri dev        # desktop app with hot reload
npm run tauri build      # installers in apps/desktop/src-tauri/target/release/bundle
```

### Integration tests with community content

The engine's integration tests run against a local checkout of the community content when it is present:

```sh
git clone --depth 1 https://github.com/AuroraLegacy/elements.git fixtures/external/aurora-legacy
npm test
```

(`fixtures/external` is git-ignored. Set `AURORA_LEGACY_DIR` to use another path.)

## Using the app

1. **Content** tab → *Download* (the AuroraLegacy index URL is prefilled) or *Import XML files…*. In the desktop app
   you can also drop XML files into `Documents/dndbuilder/custom` (like Aurora's custom folder) and press *Rescan*.
2. **Characters** → *New character* (or *Import…* an Aurora `.dnd5e` file).
3. **Build**: choose class and levels, ability scores, and work through the choices. Red dots mark open choices.
4. **Equipment**: add items and equip armor, shields and weapons. AC updates automatically.
5. **Sheet**: the finished character. *Print / Save as PDF* produces a printable sheet.

Characters autosave locally. Use *Export* to get a portable `.json` file.
